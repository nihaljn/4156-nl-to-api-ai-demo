# 01 — The vague starting spec (v0)

**Slide:** How to write a spec with the agent
**Mode:** paste as-is; this is the "before" picture.

```text
Build a Java Spring Boot REST service that manages subscriptions.
Client apps create plans, subscribe customers to plans, cancel
subscriptions, check whether a subscription is active, and list
upcoming billing dates.
```

Don't let the agent implement from this. The next prompt asks it what it would have to guess.
