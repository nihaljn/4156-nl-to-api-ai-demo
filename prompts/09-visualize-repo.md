# 09 — A picture of the whole repo

**Slide:** AI-generated Visualization of our repo
**Mode:** plan mode (read-only) or a session that can publish an HTML page.

```text
Make a single-page visual map of this repository for a teammate joining
the project today. Read the code; don't change it.

Show:
1. The packages and main classes, and which calls which (one
   architecture diagram).
2. Each endpoint traced to the classes it passes through.
3. Where each spec rule (R1–R8) lives in the code, and which test files
   check it.
4. Test coverage per package from the latest JaCoCo report
   (target/site/jacoco/jacoco.csv), marking the least-covered classes.

Keep labels short. Put a one-sentence takeaway above each diagram.
```
